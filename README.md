# Market Analysis Bot — paper trading MVP

Основа для Telegram-бота анализа рынка без реальных сделок.

Каждый прогноз открывает виртуальную позицию фиксированным номиналом **$100**.
Бот может моделировать как рост (`LONG`), так и падение (`SHORT`). Реальные
ордера и подключение к брокеру в этом MVP отсутствуют.

## Что уже есть

- виртуальная позиция на каждый прогноз;
- расчёт количества актива из фиксированного номинала $100;
- LONG и SHORT;
- закрытие по целевой цене, стоп-цене или тайм-ауту;
- журнал сигналов;
- win rate, суммарный P&L, средняя доходность и profit factor;
- тесты для базовой логики.
- русские сообщения для прогнозов, позиций и статистики.

## Русский интерфейс

Форматирование пользовательских сообщений находится в `src/market_bot/i18n.py`.
Оно переводит сценарии `LONG/SHORT` в «Рост/Падение», причины закрытия — в
русские подписи, а числа отображает в привычном формате: `1 234,56`.

## Логика бумажной сделки

Для LONG:

```text
P&L = (цена закрытия - цена входа) × количество
```

Для SHORT:

```text
P&L = (цена входа - цена закрытия) × количество
```

Сейчас комиссию можно задавать при создании счёта. По умолчанию она равна
нулю, чтобы сначала было проще проверять качество сигналов.
