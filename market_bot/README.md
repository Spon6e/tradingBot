# Market Analysis Bot

Telegram-бот анализа рынка без реальных сделок.

Каждый прогноз открывает виртуальную позицию фиксированным номиналом **$100**.
Бот может моделировать как рост (`LONG`), так и падение (`SHORT`). Реальные
ордера и подключение к брокеру в этом MVP отсутствуют.

## Что уже есть

- виртуальная позиция на каждый прогноз;
- расчёт количества актива из фиксированного номинала $100;
- LONG и SHORT;
- закрытие по целевой цене, стоп-цене или тайм-ауту;
- журнал сигналов;
- win rate, суммарный P&L, средняя доходность и profit factor;
- тесты для базовой логики.
- русские сообщения для прогнозов, позиций и статистики.
- технический анализ по EMA 20/50, RSI и ATR;
- публичные свечи Binance для криптовалют;
- источник Yahoo Finance для акций;
- команды Telegram `/analyze`, `/positions`, `/history`, `/stats` и `/help`.
- SQLite-хранилище, сохраняющее прогнозы после перезапуска;
- фоновое обновление открытых позиций раз в минуту.

## Важно

Бот строит эвристические сценарии на основе исторических свечей. Это не
финансовая рекомендация и не гарантия роста или падения цены. Все сделки в
проекте виртуальные; подключение реальных ордеров отсутствует.

## Структура проекта

```text
src/market_bot/
  analysis.py       технический анализ EMA, RSI и ATR
  market_data.py    источники свечей криптовалют и акций
  models.py         модели сигналов и позиций
  paper_trading.py  виртуальные сделки и статистика
  storage.py        сохранение в SQLite
  telegram_bot.py   русскоязычный Telegram-интерфейс
  service.py        связывает данные, анализ и paper trading
tests/               автоматические проверки
```

## Русский интерфейс

Форматирование пользовательских сообщений находится в `src/market_bot/i18n.py`.
Оно переводит сценарии `LONG/SHORT` в «Рост/Падение», причины закрытия — в
русские подписи, а числа отображает в привычном формате: `1 234,56`.

## Логика бумажной сделки

Для LONG:

```text
P&L = (цена закрытия - цена входа) × количество
```

Для SHORT:

```text
P&L = (цена входа - цена закрытия) × количество
```

Сейчас комиссию можно задавать при создании счёта. По умолчанию она равна
нулю, чтобы сначала было проще проверять качество сигналов.

## Запуск Telegram-бота

Установите проект с Telegram-зависимостью:

```text
pip install -e ".[telegram]"
```

Создайте бота через `@BotFather`, задайте токен и запустите:

```text
set TELEGRAM_BOT_TOKEN=ваш_токен
python -m market_bot
```

После установки также доступна команда:

```text
market-analysis-bot
```

В PowerShell вместо `set` используйте:

```text
$env:TELEGRAM_BOT_TOKEN = "ваш_токен"
python -m market_bot
```

Доступные команды:

- `/analyze BTCUSDT` — анализ криптовалюты;
- `/analyze AAPL 1d` — анализ акции;
- `/positions` — открытые виртуальные позиции;
- `/history` — закрытые прогнозы;
- `/stats` — статистика.

По умолчанию история хранится в файле `market_bot.sqlite3`. Другой путь можно
задать через переменную `MARKET_BOT_DB`.
